# QA evidence

Before-and-after proof (screenshots, GIFs, log excerpts) from QA, linked from this repository's issues and PRs. One
folder per issue: `qa/<issue>/<YYYYMMDD>-<check-slug>-before.png` and `…-after.png`. This branch is add-only: never
delete, overwrite or force-push anything here, and never merge it. Nothing here may show personal data, tokens,
account or device IDs, IP addresses or e-mails. How to add and link files: the `qa-evidence` skill.
